# Projeto Prático : Página de Receita

Este repositório contém a resolução obtida no projeto prático do módulo "Fundamentos do HTML e CSS" da Formação Full-Stack da Rocketseat. 

Veja o resultado em : https://erick-p-calauro.github.io/projeto-receita-fullstack/

## Quais conhecimentos foram demandados ?

O projeto foi realizado utilizando exclusivamente HTML e CSS, sob a restrição de não utilizar layout Flexbox. 
Como o nome do módulo sugere, o objetivo dessa atividade era praticar os conceitos mais básicos e fundamentais do HTML e CSS.

## Créditos

O design do projeto foi fornecido como material pela Rocketseat.
A implementação é de minha autoria, assistida pelas aulas do módulo indicado.
